# Εργαστήρια — Εισαγωγή στον Προγραμματισμό :leopard:

Υλικό εργαστηρίων για το μάθημα **Εισαγωγή στον Προγραμματισμό** (κ08) του Τμήματος
Πληροφορικής και Τηλεπικοινωνιών του ΕΚΠΑ.

Τα έντεκα εργαστήρια ξεκινούν από το πρώτο άνοιγμα ενός τερματικού και φτάνουν μέχρι
τις αυτοαναφορικές δομές και τη διαχείριση αρχείων στη γλώσσα C. Κάθε εργαστήριο
είναι αυτοτελές: περιέχει τη θεωρία που χρειάζεται, ασκήσεις με παραδείγματα
εκτέλεσης, και - στα περισσότερα - ένα παράρτημα αποσφαλμάτωσης.

## Τα εργαστήρια

| # | Εργαστήριο | Θέματα |
|---|---|---|
| 0 | [Καλημέρα Κόσμε!](labs/lab00/) | webmail, Piazza, λογαριασμός Linux, ssh, shell, editors, Hello World |
| 1 | [Unix και Git](labs/lab01/) | εντολές Unix, δικαιώματα, ανακατεύθυνση, σωληνώσεις, git, GitHub |
| 2 | [Προγραμματιστικά Περιβάλλοντα](labs/lab02/) | VS Code, scp / WinSCP, μεταγλώττιση, `scanf` · *Πράξη 1η: συντακτικά λάθη* |
| 3 | [Μεταβλητές και Δομές Ελέγχου](labs/lab03/) | τύποι, `while` / `for` / `do…while`, `if…else`, σειρές · *Πράξη 2η: λογικά λάθη* |
| 4 | [Είσοδος και Έξοδος Χαρακτήρων](labs/lab04/) | `getchar`, `putchar`, ASCII, κωδικοποίηση |
| 5 | [Συναρτήσεις και Αναδρομή](labs/lab05/) | συναρτήσεις, αναδρομή, Collatz, Fibonacci |
| 6 | [Δείκτες και Πίνακες](labs/lab06/) | δείκτες, αριθμητική δεικτών, πίνακες, κόσκινο Ερατοσθένη |
| 7 | [Πολυδιάστατοι Πίνακες](labs/lab07/) | 2Δ πίνακες, `malloc` / `free` · *Πράξη 3η: σφάλματα μνήμης και `gdb`* |
| 8 | [Συμβολοσειρές και Ορίσματα](labs/lab08/) | `string.h`, `argc` / `argv` · *Πράξη 4η: αποσφαλμάτωση* |
| 9 | [Δομές και Αυτοαναφορικές Δομές](labs/lab09/) | `struct`, συνδεδεμένες λίστες, δυαδικά δένδρα · *Πράξη 5η: `valgrind`* |
| 10 | [Είσοδος και Έξοδος με Αρχεία](labs/lab10/) | ρεύματα, αρχεία κειμένου και δυαδικά · *παράρτημα: πολλαπλά αρχεία και `make`* |
